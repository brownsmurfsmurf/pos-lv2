# Lv2 簡易POSアプリ（Tech0 個人課題）

要求一覧（Lv1・Lv2）から、要件定義 → 設計 → テスト仕様 → コードまでを AI と一緒に作った課題です。
1 回目の講師指摘（要求にない機能が入っていた、取引日の生成元が未定義）を受けて、要件定義からやり直しました。
**提出物は、やり直し後の v2 と、そのコードです。**

## 読み方の約束

- **要件番号**（FR-xx、N-xx、DT-x、P-x）は、要件定義書 v2 から設計・テスト・コードまで共通です
- **K-n**（確認事項）は、要求に書かれていないため決めなかったこと。設計で仮に置いた値には ★ を付け、K 番号と結びつけています
- **D-xxx**（決定ログ）は、人が決めたこと。理由は決定ログにあります

## 提出に含めないもの

`不要/` にまとめてあります。1 回目の成果物、やり直しの途中版、詳細版のカリキュラムなど、経緯として残しているだけのものです。
